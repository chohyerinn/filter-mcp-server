아래 프롬프트에서 {SERVER_NAME}만 자기 서버 이름으로 바꿔 사용한다.

서버 이름:
- filter-naive
- filter-bloom
- filter-counting-bloom
- filter-cuckoo
- filter-surf

============================================================
쉬운 실험 프롬프트
============================================================

{SERVER_NAME} 서버를 실제 MCP tool로 호출해서
"검색창 자동완성 사전 관리" 실험을 해줘.

상황:
검색 서비스에 아래 10개의 검색어가 등록되어 있다고 가정해.

["app", "apple", "application", "appstore", "banana", "bank", "baseball", "camera", "campus", "car"]

먼저 이 10개 검색어로 build()를 호출해줘.

config는 아래 값을 사용해줘.

{
  "target_fpr": 0.01,
  "expected_items": 10,
  "fingerprint_bits": 12,
  "bucket_size": 4,
  "counter_bits": 4,
  "suffix_bits": 8,
  "trie_depth": 8
}

그 다음 아래 상황을 하나씩 실제 MCP tool로 확인해줘.

1. 사용자가 "apple"을 검색했다.
   -> 이 검색어가 사전에 있는지 contains("apple")로 확인해줘.

2. 사용자가 "applf"라고 오타를 입력했다.
   -> 실제로 없는 검색어인데, 서버가 있다고 착각하는지 contains("applf")로 확인해줘.

3. "applepay"가 새 트렌드 검색어가 되었다.
   -> insert("applepay")로 추가하고, contains("applepay")로 확인해줘.

4. "appstore"는 오래된 검색어라 삭제해야 한다.
   -> delete("appstore")로 삭제하고, contains("appstore")로 확인해줘.

5. 사용자가 검색창에 "app"까지만 입력했다.
   -> prefix_query("app")로 자동완성 후보가 몇 개인지 확인해줘.

6. 사전식 순서로 "app" 이상, "banana" 미만의 검색어 묶음을 보고 싶다.
   -> range_query("app", "banana")로 확인해줘.

7. 이 서버가 메모리를 얼마나 쓰는지 확인하고 싶다.
   -> memory_usage()로 확인해줘.

8. 없는 검색어를 있다고 착각하는 비율을 보고 싶다.
   -> 없는 검색어 1000개를 만들어 false_positive_rate(absent_queries_1000)를 호출해줘.

   absent_queries_1000 구성:
   - 오타형 500개: applf_000 ~ applf_249, bananna_000 ~ bananna_249
   - 랜덤형 500개: xyz_000 ~ xyz_249, qwerty_000 ~ qwerty_249

결과는 표로 정리해줘.

표에는 다음 항목을 넣어줘:
| 상황 | 호출한 MCP method | 결과 | 지원 여부 | 걸린 시간 | 짧은 해석 |

중요:
- 반드시 실제 {SERVER_NAME} MCP tool 호출 결과만 사용해줘.
- 지원하지 않는 기능은 N/A라고 써줘.
- 추측해서 결과를 만들지 마.
- prefix_query나 range_query가 matched_count만 반환하면, keyword 예시는 build dataset 기준 설명으로만 적어줘.

마지막에 이 서버가 검색창 자동완성 사전 관리에서 어떤 경우에 적합하고,
어떤 trade-off 때문에 부적합한지 각각 1문장씩 정리해줘.

============================================================
발표자가 이해할 실험 의미
============================================================

| 상황 | MCP 호출 | 의미 |
| --- | --- | --- |
| apple이 검색어 사전에 있나? | contains("apple") | 등록된 검색어 확인 |
| applf는 오타인데 있다고 착각하나? | contains("applf") | false positive 확인 |
| applepay가 새로 유행함 | insert("applepay") | 새 트렌드 키워드 추가 |
| appstore는 오래된 검색어라 제거 | delete("appstore") | 만료 키워드 삭제 |
| 사용자가 app까지만 입력함 | prefix_query("app") | 자동완성 후보 수 확인 |
| app부터 banana 전까지 묶음 보기 | range_query("app", "banana") | 사전식 구간 조회 |
| 서버 운영 비용 확인 | memory_usage() | 메모리 비교 |
| 없는 검색어를 있다고 착각하는 비율 | false_positive_rate() | 오탐률 비교 |
